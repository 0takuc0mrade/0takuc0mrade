# Peter June

I build verifiable, security-conscious systems at the intersection of **blockchain, autonomous agents, and zero-knowledge technology**.

My recent work spans production-minded smart contracts, private credentials, agent payment controls, on-chain games, and open-source protocol hardening. I care about the less glamorous parts too: threat boundaries, failure modes, test coverage, deployment evidence, and making complicated systems understandable to the people using them.

## What I am focused on

- Shipping on-chain products with real contracts, testnet deployments, and end-to-end proof.
- Designing safer financial infrastructure for autonomous agents.
- Exploring privacy-preserving identity, credentials, policy enforcement, and settlement.
- Contributing security fixes, reliability improvements, and regression coverage across Web3 projects.
